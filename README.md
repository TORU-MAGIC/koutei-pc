# Magic Show Cue

マジックショー向けのローカル音楽キュー再生アプリです。GitHub Pagesでは `index.html` が本番用の入口になります。

音楽キュー単体で使う場合は `music.html` を開いてください。

## スマホ効果音パッド

正解・不正解とマジック用4種類を、大きな6ボタンでスマホから直接鳴らせます。音声ファイルの転送や選択は不要です。

使い方:

1. PCとスマホを、信頼できる同じ自宅Wi-Fiへ接続する。
2. PCで `start-mobile-server.cmd` をダブルクリックする。
3. 黒い画面に表示された、アクセスキー付きの緑色URLをスマホへ正確に入力する。
4. iPhoneはSafari、AndroidはChromeで開く。
5. `音を準備する` をタップし、`効果音：準備完了` と `6 / 6 準備` を確認する。
6. 6つの大きなボタンから効果音を再生する。緊急時は右上の `全停止` を押す。
7. 本番中はPCの黒い画面とスマホ画面を閉じず、スマホを前面表示したまま使用する。

配信サーバーは、現在のLANアドレス1つだけで待ち受けます。スマホ画面と内蔵WAV 6ファイル以外は公開せず、同一サブネットと起動ごとのランダムなアクセスキーで接続を制限します。ファイアウォール設定は自動変更しません。

音はスマホ自身から出ます。スマホからPCのBGMを遠隔操作する機能ではありません。

注意:

- Windowsの確認が表示された場合、信頼できる `プライベートネットワーク` だけ許可する。公共Wi-Fiでは使用しない。
- 黒い画面に `Public` の警告が出てスマホから開けない場合、信頼できる自宅Wi-Fiであることを確認してから、WindowsのWi-Fi設定でネットワークプロファイルを `Private` に変更する。
- Bluetoothスピーカーでは機器側の遅延が加わる。最小遅延を優先する場合は有線またはUSBオーディオを使用する。
- `remote-volume-helper` はWindows専用で、スマホ効果音パッドでは使用しない。

## 基本の流れ

1. `music.html` を Microsoft Edge または Google Chrome で開く。
2. `＋ 音源` から演目順に曲を追加する。
3. 各曲で `フェード`、`間隔`、`演技終了時`、`曲終了時` を設定する。
4. `開始` で曲を再生する。
5. 演技が先に終わったら `演技終了` を押す。
6. 曲が先に終わった場合は、初期設定ではそのまま待機する。

## ビンゴ合体版

1. `index.html` を Microsoft Edge または Google Chrome で開く。
2. ショー前に `音楽準備` を押して、音楽キューの曲を追加または再接続する。
3. `ビンゴへ戻る` でビンゴ画面に戻る。
4. ビンゴ演目を行う。
5. 次の演目へ進む時に `ビンゴ終了 → 音楽スタート` を押す。
6. ビンゴ側の音を止め、ビンゴアプリを終了してから音楽キュー画面へ切り替え、1曲目を頭から再生する。

## 重要な設定

- `演技終了時: 次曲を自動開始`
  - `演技終了` を押すと現在曲をフェードアウトし、設定した間隔の後に次の曲を自動で開始します。
- `演技終了時: 次曲を待機`
  - フェードアウト後、次の曲を選択した状態で止まります。
- `演技終了時: 停止のみ`
  - フェードアウトして止まります。
- `曲終了時: 待機`
  - 演技が曲より長くなった時、曲が終わったまま待機します。
- `曲終了時: 次曲を自動開始`
  - 曲が自然に終わったら、間隔後に次の曲を開始します。

## Bluetoothリモコン

音量＋/−だけのBluetoothコントローラー向けの操作です。音量が変わらないように、本番では先に `start-remote-helper.cmd` を起動してください。この補助スクリプトが起動時のWindows音量をロックし、音量キーをブロックまたは即復元しながら、音量−をフェードアウト、音量＋を次曲スタートとしてアプリに直接送ります。

- 音量−: 現在の曲をフェードアウトし、次の曲を待機状態にします。各曲の「演技終了時」設定に関係なく、自動再生はしません。
- 音量＋: 待機している次の曲を頭からスタートします。再生中に押した場合は、次の曲へ進んでスタートします。

使い方:

1. 以前に起動した黒い補助画面が残っている場合は、いったん閉じる。
2. `start-remote-helper.cmd` を起動し、表示された黒い画面を閉じずに残す。
3. 本番用は `index.html`、音楽単体用は `music.html` を開く。
4. アプリ画面を一度クリックしてフォーカスを当てる。
5. できれば `本番` または全画面表示で使う。
6. 黒い補助画面に `Command bridge is listening` と表示されていることを確認する。
7. 画面の `Bluetoothリモコン` 表示が、音量−/＋で反応し、Windows音量が起動時の値から変わらないことを確認する。

補助スクリプトを使わずに音量−/＋を押すと、機種やWindows設定によってOS音量が変わる場合があります。本番では必ず補助スクリプトを起動してください。もしWindows音量表示が一瞬出ても、音量が起動時の値へ戻っていれば補助スクリプトが復元しています。長押しによる連続操作は誤作動防止のため約0.7秒に1回だけ反応します。

それでも音量が変わる場合:

1. `disable-bluetooth-absolute-volume-admin.cmd` を右クリックして、管理者として実行する。
2. Bluetoothを一度オフ/オンする。直らなければWindowsを再起動する。
3. もう一度 `start-remote-helper.cmd` を起動してから `index.html` を開く。

これはBluetooth機器の「絶対音量」をWindows側で無効化するための対策です。元に戻したい場合は `restore-bluetooth-absolute-volume-admin.cmd` を管理者として実行してください。

## 効果音（低遅延）

右側の「効果音」には3つの独立したスロットがあります。

1. 各スロットの `WAV / MP3を選択` から効果音ファイルを選ぶ。
2. 効果音名と音量を設定する。
3. アプリ画面を一度クリックし、`効果音：準備完了` を確認する。
4. `テスト再生` で確認し、必要なら同じスロットの `停止` で止める。
5. 「リモコン入力テスト」で実機ボタンを押し、最後のキー名と受信時刻を確認する。
6. 使いたいスロットの `割り当て` を押してから、同じ実機ボタンをもう一度押す。

選択した音声は、その場でWeb Audio APIのAudioBufferへデコードしてメモリに保持します。キー入力時には新しいAudioBufferSourceNodeだけを作って即時再生するため、BGM再生中でもBGMを止めずに重ねて鳴らせます。低遅延を優先する場合はWAVを推奨します。

効果音の再生・音量・停止はBGMとは別系統です。BGMの再生位置、マスター音量、フェード、停止、曲送りには影響しません。同じキーの長押しは `repeat` と効果音専用100msデバウンスで抑止します。

F8、F9、音量＋/−、メディア操作キー、Space、Enter、F、S、左右矢印など、既存のBGM操作に使うキーは警告され、効果音には割り当てられません。`start-remote-helper.cmd` 使用中の音量＋/−はF8/F9として表示され、従来どおりBGM操作専用です。

効果音名、音量、キー割り当て、再接続用のファイル名はブラウザに自動保存されます。ブラウザの安全仕様により音声ファイル本体は保存されないため、ページ再読み込み後は各スロットでファイルを再選択してください。

## 保存について

- `保存` は、このブラウザにセットリスト設定を保存します。
- `書き出し` は、セットリストを JSON ファイルとして保存します。
- ブラウザの安全仕様により、曲ファイルそのものは自動復元されません。
- 翌日や別PCで使う時は、`読み込み` 後に `↺ 再接続` を押し、同じファイル名の音源を選んでください。

## 本番前チェック

- PCを電源につなぐ。
- OSの通知音、スリープ、Bluetooth切断を止める。
- `start-remote-helper.cmd` を起動し、音量−/＋を押してもWindows音量が起動時の値から変わらないことを確認する。
- 効果音ファイルを再選択し、`効果音：準備完了` を確認する。
- BGMを流しながら効果音1～3をテスト再生し、割り当てた実機キーでも一度ずつ鳴らす。
- 本番と同じスピーカーで全曲を一度流す。
- `本番` ボタンで大画面表示にし、必要なら `⛶` で全画面にする。
- 対応ブラウザなら `画面維持` を押して画面スリープを抑止する。
